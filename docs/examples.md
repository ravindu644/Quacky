# Examples

Worked scripts that build from a single line to a complete routine. Each one is a valid program;
rehearse any of them with a dry run (`quacky file.qk`) to see the transcript before running it for
real. For the features used here, see [language.md](language.md) and [keys.md](keys.md).

## 1. Hello

The smallest useful script. `type` sends the text and presses Enter.

```
type Hello from Quacky!
```

## 2. A short routine

Open something, wait for it, type into it. `sleep` pauses once; chords press keys together.

```
super + r              # open the run dialog on the host
sleep 400              # give it a moment to appear
type notepad           # type presses Enter at the end, which launches it
sleep 600
type Typed by a script.
```

## 3. Variables and interpolation

Compute a value, then drop it into typed text with `$name` and `${expr}`.

```
user  = "ada"
items = 3
type Welcome, $user.
type You have ${items * 2} messages.
```

## 4. Pacing the output

`delay` sets a pause after every step, so the typing looks steady instead of instant.

```
delay 40               # 40 ms after each step from here on
type one
type two
type three
delay 0                # back to full speed
```

## 5. Selecting with held keys

`hold` keeps a key down across several lines. Here Shift stays down while the arrows move, which
selects text, then `release` lets go.

```
hold shift
down
down
right
release shift
ctrl + c               # copy the selection
```

## 6. Counting with a loop

A `for` range counts inclusively. The loop variable is available inside the body.

```
for n in 1 .. 5 do
  type Item $n
done
```

The same thing with `while`, which is useful when the step is not a simple count:

```
n = 0
while n < 10 do
  type $n\c
  type , \c
  n = n + 2
done
```

## 7. A function

Group steps into a named function and call it with arguments. Functions can be defined in any order.

```
func field label value
  type $label: $value
end

field("name", "Ada")
field("role", "pioneer")
```

## 8. Branching on a value

`if` needs a bool, so compare explicitly. Each branch can type something different.

```
hour = 9
if hour < 12 then
  type Good morning.
elif hour < 18 then
  type Good afternoon.
else
  type Good evening.
fi
```

## 9. Putting it together

A complete routine: open an editor, write a short note with a little computed content, and save it.
This uses variables, interpolation, a loop, timing, and chords together.

```
const PAUSE = 500

func line text
  type $text            # type ends each line with Enter for us
end

super + r
sleep PAUSE
type gedit              # type presses Enter, which launches the editor
sleep PAUSE

line("Notes for today")
line("================")
for n in 1 .. 3 do
  type Task $n to do    # $n only interpolates inside a type line, so type here directly
done
line("")
line("Generated by Quacky.")

ctrl + s               # save
```

Rehearse it first with `quacky routine.qk`, read the transcript, and only then run it with
`quacky --hid /dev/hidg0 routine.qk`.
