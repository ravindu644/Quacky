# Examples

Worked scripts that build from a single line to a complete routine. Each one is a valid program;
rehearse any of them with a dry run (`quacky file.qk`) to see the transcript before running it for
real. For the features used here, see [language.md](language.md) and [keys.md](keys.md).

Prefer ready-to-run files? The [`examples/`](../examples/) directory holds the same spirit as
standalone scripts: [`functions.qk`](../examples/functions.qk) tours parameters, `return` and
recursion, and [`pad-numbers.qk`](../examples/pad-numbers.qk) zero-pads numbers (`00`-`99`,
`000`-`999`) with a small helper, since the language has no printf.
[`os-detect.qk`](../examples/os-detect.qk) tells Windows, macOS and Linux apart by reading the
host's lock-key LEDs; unlike the others it cannot be dry-run (it needs a real host), so run it with
`--hid`.

## 1. Hello

The smallest useful script. `typeln` types the text and presses Enter (`type` alone would not).

```
typeln Hello from Quacky!
```

## 2. A short routine

Open something, wait for it, type into it. `sleep` pauses once; chords press keys together.

```
super + r              # open the run dialog on the host
sleep 400              # give it a moment to appear
typeln notepad         # typeln types the name and presses Enter, launching it
sleep 600
typeln Typed by a script.
```

## 3. Variables and interpolation

Compute a value, then drop it into typed text with `$name` and `${expr}`.

```
user  = "ada"
items = 3
typeln Welcome, $user.
typeln You have ${items * 2} messages.
```

## 4. Pacing the output

`delay` sets a pause between each typed step, so the typing looks steady instead of instant.

```
delay 40               # 40 ms between each step from here on
typeln one
typeln two
typeln three
delay 0                # back to full speed
```

## 5. Selecting with held keys

`hold` keeps a key down across several lines. Here Shift stays down while the arrows move, which
selects text, then `release` lets go.

```
hold shift
down
down
right
release shift
ctrl + c               # copy the selection
```

## 6. Counting with a loop

A `for` range counts inclusively. The loop variable is available inside the body.

```
for n in 1 .. 5 do
  typeln Item $n
done
```

A `while` loop, building a single line with `type` (which adds no Enter) and ending it with a bare
`typeln`:

```
n = 0
while n < 10 do
  type ${n},            # type keeps everything on one line
  n = n + 2
done
typeln                  # a bare typeln ends the line
```

## 7. A function

Group steps into a named function and call it with arguments. Functions can be defined in any order.

```
func field label value
  typeln $label: $value
end

field("name", "Ada")
field("role", "pioneer")
```

## 8. Branching on a value

`if` needs a bool, so compare explicitly. Each branch types a different line.

```
hour = 9
if hour < 12 then
  typeln Good morning.
elif hour < 18 then
  typeln Good afternoon.
else
  typeln Good evening.
fi
```

## 9. Putting it together

A complete routine: open an editor, write a short note with a little computed content, and save it.
This uses variables, interpolation, a loop, timing, and chords together.

```
const PAUSE = 500

func line text
  typeln $text          # typeln ends each line with Enter
end

super + r
sleep PAUSE
typeln gedit            # typeln types the name and presses Enter, launching the editor
sleep PAUSE

line("Notes for today")
line("================")
for n in 1 .. 3 do
  typeln Task $n to do  # interpolation happens in a type/typeln line, so write it here
done
line("")
line("Generated by Quacky.")

ctrl + s               # save
```

Rehearse it first with `quacky routine.qk`, read the transcript, and only then run it with
`quacky --hid /dev/hidg0 routine.qk`.

## 10. Typing a whole file

For a long passage, keep the text in a file next to the script and type it in one line. The contents
go out verbatim, so nothing inside needs escaping.

```
type_file "lorem.txt"      # type the file exactly, no trailing Enter
typeln_file "lorem.txt"    # type it and press Enter at the end
```

The path is relative to the script, and `quacky --check script.qk` resolves and validates the file
(it must be real UTF-8 text, not a binary blob) before anything is typed. See
[language.md](language.md#typing-a-file) for the details.

## 11. Splitting a script into modules

Keep shared constants and helpers in their own file and `import` it. Relative paths resolve next to
the file that writes the import, and a file is imported only once.

```
# lib/pace.qk, a reusable module
const TYPING = 15
func slow_line text
  keydelay 90
  typeln $text
  keydelay TYPING
end
```

```
# demo.qk, the script you run
import lib/pace.qk          # TYPING is now set; slow_line() is now callable
keydelay TYPING
slow_line("typed deliberately")
typeln and the rest at normal speed
```

Rehearse `demo.qk` with a dry run as usual; a missing module or a syntax error in one is caught by
`quacky --check demo.qk` before anything is typed. See
[language.md](language.md#modules-import) for the rules.
